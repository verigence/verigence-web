# Verigence Web Brand Assets

This folder is the checked-in brand baseline for the Verigence Web application.

Use the SVG assets for normal UI rendering and the PNG assets when a raster asset is explicitly required.

See [`docs/BRANDING_GUIDELINES.md`](../../docs/BRANDING_GUIDELINES.md) for palette, typography, spacing, permitted variants and usage rules.

## Recommended defaults

- Header / navigation: `svg/verigence-logo.svg`
- Compact shell / avatar: `svg/verigence-mark.svg`
- Browser favicon: `icons/favicon.svg`
- PWA / app icon: `icons/app-icon-192.png` and `icons/app-icon-512.png`
- Brand tokens: `brand-tokens.css`

The user-approved PNG artwork is preserved as the visual reference for these implementation assets.
