Review notes

What this mockup pack intentionally leaves configurable

26 vs 29 documentsUI shows applicable counts. Final physical catalogue is reconciled in UAT.
Aadhaar retentionUI is masked; backend raw-retention policy is not invented here.
VIN 8 vs 17Only the Rule Engine can state Match/Mismatch once a published algorithm exists.
Audit completionReview-before-complete is rule/policy driven; PC capture can be complete while Audit remains In Progress.
Design gate: these are static planning mockups only. They do not authorize changes to production React, APIs, schemas, DI profiles or Android native code. After business/UX approval, UC03 Implementation Design should convert this interaction contract into exact Audit Core APIs, migrations, DI profiles and Web/Android components.
